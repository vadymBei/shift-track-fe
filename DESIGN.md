# ShiftTrack — дизайн-система

Цей документ описує, як має виглядати й поводитися інтерфейс ShiftTrack. Його мета — щоб усі сторінки виглядали як один продукт, однаково добре працювали у світлій і темній темах і щоб будь-хто (людина чи AI-асистент) міг переробити сторінку без додаткових пояснень.

> **Головне правило:** не вигадуй стиль на місці. Якщо потрібного патерну тут немає — спочатку додай його в цей документ, потім використовуй.

**Обраний напрям:** «Скляна аврора» (варіант A з макетів). Каркас — бічне меню.

**Табель** (`features/organization/timesheet/pages/timesheet`) теж переведено на нову систему: таблиця з закріпленими колонками ПІБ і підсумків, кольорові плашки змін, виділення діапазону мишкою, діалог `employee-shift-dialog` з вкладкою історії.

---

## 1. Принципи

1. **Сучасно й спокійно.** Багато повітря, м'які заокруглення, мінімум ліній. Акцентний фіолетовий — лише для головних дій і активних станів, а не для всього підряд.
2. **Скло для каркаса, суцільні поверхні для даних.** Напівпрозорі розмиті панелі («скло») використовуємо для навігації, контейнерів сторінок і промо-блоків. Таблиці, форми й діалоги стоять на суцільному фоні, щоб текст легко читався.
3. **Дві теми з першого дня.** Жодних захардкоджених кольорів. Усе через токени (розділ 3), тоді темна тема працює автоматично.
4. **PrimeNG — єдине джерело компонентів.** Bootstrap, ngx-bootstrap і ngx-color повністю прибрано з проєкту.
5. **Однакові задачі — однакові рішення.** Таблиця, фільтр, модальне вікно, підтвердження видалення виглядають і працюють однаково на всіх сторінках.

## 2. Візуальна мова: «скло й градієнти»

| Шар | Що це | Як виглядає |
|---|---|---|
| **Фон застосунку** | `body` | М'який градієнт (світла тема — пастельне зображення, темна — темно-фіолетові «плями» на майже чорному). Фон фіксований, не прокручується. |
| **Скло** | Верхня навігація, контейнер сторінки, промо-картки | `--app-glass-bg` + `backdrop-filter: blur(var(--app-glass-blur))` + тонка рамка `--app-glass-border` + `--app-shadow-lg`. |
| **Поверхня** | Таблиці, форми, діалоги, картки з даними | Суцільний `--p-content-background`, рамка `--p-content-border-color`, радіус `--app-radius-lg`. |
| **Акцент** | Головна кнопка, активний пункт меню, фокус | `--p-primary-color` та відтінки `--p-primary-50…950`. |

Готові утиліти (див. `src/styles.scss`):

- `.glass` — скляна панель.
- `.surface` — суцільна картка.
- `.page` / `.page-header` / `.page-title` / `.page-subtitle` / `.page-actions` — каркас сторінки (розділ 6).

**Базові стилі:** замість Bootstrap Reboot у `styles.scss` є власне мінімальне скидання (`box-sizing`, відступи заголовків, шрифти форм) і утиліта `.visually-hidden`. Утилітних класів на кшталт `mb-3`, `d-flex` більше немає — відступи задаються в стилях компонента.

**Важливо:** `backdrop-filter` створює окремий шар відображення, тож спливаючі елементи всередині скла можуть ховатися під сусідньою панеллю. Тому всі оверлеї PrimeNG (`p-select`, `p-autocomplete` тощо) глобально рендеряться в `<body>` (`providePrimeNG({ overlayOptions: { appendTo: 'body' } })` в `app.config.ts`). Для `p-datepicker`, `p-password` і `p-menu` вказуйте `appendTo="body"` явно.

**Не можна:** скло всередині скла, скло під таблицею з великою кількістю рядків, більше одного рівня розмиття на екрані (дорого для продуктивності).

## 3. Теми й токени

### Як працює тема

- Перемикання — через `ThemeService` (`src/app/shared/services/theme.service.ts`). Режими: `light`, `dark`, `system`. Вибір зберігається в `localStorage` (`st-theme`).
- Темна тема = клас `app-dark` на `<html>` (так налаштовано `providePrimeNG` → `darkModeSelector: '.app-dark'`).
- Скрипт в `index.html` ставить клас ще до завантаження Angular, щоб не було «блимання» світлої теми.
- Кнопка перемикання — компонент `<app-theme-toggle>`.

### Токени

**Кольори — тільки через CSS-змінні.** Захардкоджені `#hex` у компонентах заборонені (виняток — ілюстрації та логотипи).

PrimeNG-токени (генерує тема, автоматично змінюються в темному режимі):

| Призначення | Токен |
|---|---|
| Основний текст | `--p-text-color` |
| Другорядний текст | `--p-text-muted-color` |
| Акцент | `--p-primary-color`, `--p-primary-50` … `--p-primary-950` |
| Текст на акценті | `--p-primary-contrast-color` |
| Фон поверхні | `--p-content-background` |
| Фон при наведенні | `--p-content-hover-background` |
| Рамка | `--p-content-border-color` |
| Нейтральна шкала | `--p-surface-0` … `--p-surface-950` |
| Статуси | `--p-green-500`, `--p-red-500`, `--p-orange-500`, `--p-sky-500` (краще — компоненти `p-tag`/`p-message` з `severity`) |

Токени застосунку (`--app-*`, визначені в `src/styles.scss` для обох тем):

| Токен | Призначення |
|---|---|
| `--app-bg` | Фон застосунку (градієнт/зображення) |

Основний колір бренду — `#6200ea` (шкала в `src/app/shared/constants/primeng-preset.ts`). Щоб змінити бренд — правимо тільки цей файл.

## 4. Типографіка

- Шрифт: **Inter Variable** (пакет `@fontsource-variable/inter`, без зовнішніх CDN). Цифри в таблицях — `font-variant-numeric: tabular-nums` (клас `.tabular`).
- Шкала:

| Роль | Розмір / вага | Де |
|---|---|---|
| Заголовок сторінки | 24px / 600 | `.page-title` |
| Заголовок секції / картки | 18px / 600 | `p-card` title, `h2` у сторінці |
| Основний текст | 14px / 400 | За замовчуванням |
| Дрібний текст, підписи | 12–13px / 400–500 | Підказки, метадані, `p-message size="small"` |

- Не використовуємо `font-weight: 800` і розміри > 32px усередині застосунку (лише лендінг/логін).

## 5. Простір, радіуси, тіні

- Сітка відступів кратна **4px**: 4, 8, 12, 16, 24, 32, 48.
- Відступ сторінки від країв: 24px (десктоп), 16px (мобільний).
- Відстань між блоками на сторінці: 16–24px. Між полями форми: 16px.
- Радіуси: інпути й кнопки — як у теми PrimeNG; картки й таблиці — `--app-radius-lg`; великі скляні панелі — `--app-radius-xl`.
- Тіні тільки з токенів `--app-shadow-*`. На поверхнях усередині скла тіні зазвичай не потрібні.

## 6. Каркас застосунку

```
┌──────────────┐ ┌──────────────────────────────────────────────┐
│ ◆ ShiftTrack │ │ Заголовок сторінки          [Фільтр] [+ Додати]│ ← .page-header
│              │ │ Короткий опис                                  │
│ ▣ Табель     │ ├──────────────────────────────────────────────┤
│ ☀ Відпустки  │ │                                              │
│ ▤ Відрядження│ │          контент (.surface / p-table)        │
│ …            │ │          прокручується окремо                │
│              │ │                                              │
│──────────────│ │                                              │
│ (ВБ) Вадим ▴ │ │                                              │
│ ☾         «  │ │                                              │
└──────────────┘ └──────────────────────────────────────────────┘
  скляна бічна панель (248px / 76px згорнута)
```

- **Бічна панель** (`app-sidebar`, обгортка `.app-sidebar.glass` у `layout`): логотип, пункти меню (`core/layout/constants/nav-items.ts`), внизу — меню користувача (`app-user-menu`: `p-avatar` + `p-menu` popup), перемикач теми й кнопка згортання. Згорнута панель показує лише іконки з `pTooltip`; стан запам'ятовується (`st-sidebar-collapsed`).
- **Активний пункт:** `--p-highlight-background` / `--p-highlight-color`.
- **Мобільні та планшети (< 992px):** бічна панель ховається; зверху скляна панель `app-header` з кнопкою ☰, яка відкриває те саме меню в `p-drawer`.
- **Контент:** займає решту ширини й прокручується окремо від панелі (висота каркаса = `100vh`).
- **Шаблон сторінки:**

```html
<div class="page">
  <header class="page-header">
    <div>
      <h1 class="page-title">Співробітники</h1>
      <p class="page-subtitle">Усі працівники підрозділу</p>
    </div>
    <div class="page-actions">
      <p-button label="Додати" icon="pi pi-plus" />
    </div>
  </header>

  <section class="surface">…</section>
</div>
```

- Брейкпоінти: `576px` (телефон), `768px` (планшет), `992px` (бічна панель → висувне меню), `1440px` (широкий екран).

## 8. Патерни

### Таблиці
- `p-table` у `.surface`, без зовнішнього `showGridlines`; рядки з `hover`.
- Дії в рядку — іконки-кнопки (`text`, `rounded`) праворуч, з `pTooltip`.
- Обов'язково: стан завантаження (`[loading]`), порожній стан (`emptymessage`: іконка + текст + дія), пагінація від 20 рядків.
- Числа й час — вирівнювання праворуч, клас `.tabular`.

### Форми
- У діалогах і щільних формах — `<label>` над полем; `p-floatlabel variant="in"` — для коротких форм (логін, реєстрація).
- Помилки — `p-message severity="error" variant="simple" size="small"` під полем, показувати після `touched`/`dirty`.
- Кнопки: головна дія праворуч (`p-button`), скасування ліворуч від неї (`[text]="true"` або `severity="secondary"`).
- Під час запиту — `[loading]` на кнопці, а не спінер на всю сторінку.

### Діалоги
- Діалоги з формами відкриваємо через `DialogService` (`primeng/dynamicdialog`, у `providers` сторінки) з `showHeader: false` — заголовок, кнопка закриття й футер усередині компонента. Результат — `ref.close(true)`, якщо дані змінилися (сторінка перезавантажує список). Приклад: `features/booking/vacations/components/*`.
- `p-dialog [modal]="true"`, ширина 480px (проста форма) / 720px (складна), на мобільних — на всю ширину (`[breakpoints]="{ '576px': '95vw' }"`).
- Заголовок — дієслово + об'єкт: «Створити посаду», «Редагувати зміну».

### Сповіщення
- Успіх / помилка дії — `p-toast` (праворуч зверху, 3–5 с) через `NotificationService`: `success()`, `info()`, `warn()`, `error()`. Помилки HTTP показує `errorInterceptor` → `ErrorService` автоматично.
- Підтвердження видалення — `ConfirmService.confirmDelete({ entityName: 'посаду', itemName: position.name, onConfirm: () => … })`. Свої модалки для підтвердження не робимо.
- Помилка поля — `p-message` під полем. Помилка всієї форми — `p-message` над кнопками.

### Порожні стани та завантаження
- Ніколи не показувати порожню таблицю без пояснення.
- Порожній стан — компонент `<app-empty-state icon="pi pi-inbox" heading="…" hint="…"/>` (`shared/components/empty-state`). Модифікатори класом на елементі: `surface` (картка), `tall`, `narrow`; кнопку дії можна покласти всередину.
- Скелетони (`p-skeleton`) для карток і списків; не блокувати всю сторінку оверлеєм.

### Спільні будівельні блоки
| Що | Де | Як |
|---|---|---|
| Ініціали для аватара | `shared/utils/text.utils.ts` | `personInitials(employee)` → «БВ»; `personInitials(employee, 'name-first')` → «ВБ»; приймає й рядок fullName |
| Відмінювання числа | `shared/utils/text.utils.ts` | `pluralUk(n, 'день', 'дні', 'днів')` |
| Аватар з ініціалами | глобальний клас у `styles.scss` | `<p-avatar … styleClass="app-avatar my-avatar"/>`: кольори дає `app-avatar`, розмір — свій клас компонента |
| Плашка зміни | `features/organization/timesheet/components/shift-chip` | `<app-shift-chip [shift]="shift" size="xs/sm/md/lg/xl"/>`, без зміни — пунктирна порожня плашка (`placeholder`) |
| Фото поточного користувача | `CurrentUserPhotoService` | `photoUrl()` — спільне для меню і профілю, `refresh()` після завантаження нового |

Клітинки самого табеля мають власну розмітку (режим «Години», ховер, виділення) і `app-shift-chip` не використовують.

## 9. Доступність і поведінка

- Контраст тексту ≥ 4.5:1 в обох темах (перевіряти на склі особливо).
- Усі іконки-кнопки мають `ariaLabel` або `pTooltip`.
- Фокус видно з клавіатури (не прибирати `outline` без заміни).
- Анімації 150–250 мс, `ease-out`; поважати `prefers-reduced-motion`.
- Мова інтерфейсу — українська; дати `dd.MM.yyyy`, тиждень з понеділка (див. `primeng-uk.ts`).
